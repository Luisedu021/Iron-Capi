# Architecture Decision Records — Iron Capi

Este diretório reúne os registros de decisões arquiteturais (ADRs) do
projeto Iron Capi. Cada arquivo documenta uma decisão importante: o contexto
que a motivou, as alternativas consideradas e as consequências.

Use `0000-template.md` como base para novas decisões. Numere sequencialmente
e mantenha o status atualizado (Proposto, Aceito, Rejeitado ou Substituído).
